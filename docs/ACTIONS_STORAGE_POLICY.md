# Actions storage and automatic research

Effective 2026-11-21:

- Daily Prediction and Control retain their existing schedules, commands and data flow.
- The Daily coordinator still starts the frozen primary model and immediate canonical HTML publication.
- Control updates canonical HTML through `primary-control.yml`; it no longer starts the legacy experiment coordinator automatically.
- Background research requires an explicit manual dispatch with `run_research=true`. Automatic Daily dispatches leave it disabled. The fixed model is unchanged.
- New encrypted `primary-forecasts-*` checkpoints are retained for seven days. Canonical result updates require today's or yesterday's checkpoint. Existing checkpoint retention is not changed retroactively. Historical research/bootstrap artifacts are not deleted by this change.
- The ChatGPT daily experiment evaluation task is paused separately. Existing reports remain available subject to their existing retention; no new morning recovery snapshots are generated by that task.

Do not delete frozen snapshots or model/bootstrap parents simply by age: verify all consumers first. Do not disable the whole ensemble workflow: its primary job serves production HTML. Native Daily/Control intermediate artifacts, report archiving, encryption and publication retry protections remain intact.

This policy reduces future output. It does not delete existing artifacts or reset accrued billing usage. Public repository savings do not prove the source of private-account billable storage. The account audit found an unrelated private gallery export; its contents must not be deleted as part of prediction maintenance.
